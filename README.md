## Import or 執行? 

當你在 Python 中使用 `import` 語句匯入一個模組時，Python 直譯器會**執行該模組的所有頂層程式碼**。<br>
這表示著任何不在**函數或類別定義**內的程式碼都會被立即執行。<br>

然而，**函數和類別的定義本身並不會在 `import` 時被執行**。<br>
`import` 語句只會讀取這些定義，使得你可以在後續的程式碼中呼叫這些函數或使用這些類別。函數內部的程式碼只有在該函數被明確呼叫時才會執行。<br>

常見的技巧是使用特殊的 `__name__` 變數來控制模組被直接執行還是被匯入時的行為。<br>
當一個 Python 檔案被直接執行時，其 `__name__` 變數會被設定為字串 `"__main__"`。如果該檔案是被另一個模組匯入的，則其 `__name__` 變數會被設定為該模組的名稱。<br>

因此，你經常會看到類似以下的程式碼結構：<br>

```python
def my_function():
    print("函數內的程式碼被執行了。")

print("模組的頂層程式碼。")

if __name__ == "__main__":
    my_function() # 只有當這個檔案被直接執行時，這個函數才會被呼叫
